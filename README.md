## How to publish the next one

1. Create the bot in Grok Bot.
2. Paste `agents/*.md` from the repo. No secrets in memories.
3. Share → Public.
4. Drop the `https://x.ai/bot/...` URL back here and in that repo's `listings/SHARE_URL.txt`.
